# Dr. A. P. J. Abdul Kalam - Tribute Page

A responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam, created as part of my Day 1 internship task.

## About the Project

This project is a single-page tribute website that presents information about Dr. A. P. J. Abdul Kalam, including his biography, major achievements, and important events from his life.

## Technologies Used

- HTML5
- CSS3

## Features

- Semantic HTML structure
- Responsive design
- Biography section
- Major achievements section
- Timeline section
- Image with figure and caption
- Mobile and desktop support
- Clean and simple user interface

## HTML Semantic Elements Used

- `<header>`
- `<main>`
- `<section>`
- `<figure>`
- `<figcaption>`
- `<article>`
- `<footer>`
